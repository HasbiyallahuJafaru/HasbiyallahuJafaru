## How I Use AI in Development

- **Claude Sonnet** — complex reasoning, objection handling, compliance logic, closing sequences  
- **Claude Haiku / DeepSeek V3** — high-volume, low-latency tasks (small talk, classification, routing)  
- **Qwen / Kimi** — cost-optimised alternatives for African market products where margins are tight  
- **Claude Code + GitHub Copilot** — primary dev tools; I don't write boilerplate by hand  
- **LangGraph (TypeScript port)** — agent orchestration for multi-step sales and compliance flows  
- **Pollinations API** — free image/video generation for tier-based creative products  

The LLM routing is deliberate. DeepSeek handles qualification. Claude Haiku handles objections. Claude Sonnet closes. That's a cost curve, not a preference.
